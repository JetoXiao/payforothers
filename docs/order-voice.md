# 管理员新订单语音提醒

后台右上角「订单语音」→「开启提醒」。开启/测试会播放提示音以申请当前页面的播放权限；刷新后可保留开关及音量，但需要点击「启用声音 / 测试」。偏好按管理员 ID、后台挂载路径和当前浏览器隔离。

- 每 15 秒读取现有 `/api/v1/admin/orders`，按 ID 倒序。只针对新建父订单，包含未支付订单，不因付款或交付状态变化重复播报。
- 初次启动仅建立基线。自动检测到新增订单后播放「您有新的订单，请及时查看」，同轮多单合并一次语音；角标展示数量，可点击查看最近一单。
- Web Locks + 共享游标防止同浏览器多标签重复提醒。不支持 Web Locks 时回读共享游标去重。
- 连续扫描最多 20 页 × 100 条；错误/扫描截断不推进游标。长期休眠或超过 90 秒未成功轮询后重新建立基线，不补播历史订单。
- 网络错误 30 秒后重试；401/403 停止轮询。关闭开关、登出及组件销毁时清理计时器、请求和音频。
- 前台无变化；没有新增后端接口、数据库字段、支付或订单写入。只读现有订单 API 权限；无订单读取权限时不显示入口。
- 声音为本地生成并打包的 WAV（中文及英文），由 `scripts/build_order_voice.ps1` 可重建，不依赖浏览器 TTS 服务或发送订单到外部语音 API。
- 后台关闭、系统静音、休眠或浏览器后台节流可能导致无法播报/延迟。不是离线推送。

验证：Vitest 覆盖基线、首单、父子单去重、分页、多标签、失败及取消、过期游标、API 错误；`scripts/verify_order_voice.py` 模拟订单，检查开关/测试/音量/无权限/手机端/真实浏览器播放。测试不创建真实订单、支付或采购。
